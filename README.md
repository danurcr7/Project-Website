Sistem autentikasi pengguna sederhana yang dikembangkan menggunakan HTML, CSS, dan JavaScript. Proyek ini mencakup fitur login, pendaftaran akun (sign up), dan pemulihan kata sandi (forgot password) yang dirancang untuk mensimulasikan alur akses pengguna pada sebuah aplikasi web. Melalui proyek ini, saya mempelajari pengelolaan form, validasi input, serta pembuatan antarmuka yang mendukung pengalaman pengguna yang lebih baik.

Fitur:
- Login pengguna
- Registrasi akun (Sign Up)
- Forgot Password
- Validasi input form
- Navigasi antar halaman autentikasi
- Tampilan responsif dan mudah digunakan

Tech Stack:
- HTML
- CSS
- JavaScript

Tujuan Proyek:
Mempelajari implementasi alur autentikasi pengguna melalui fitur login, registrasi, dan pemulihan kata sandi pada aplikasi web.
